# The Excuse Your Agent Gives You

One original line an AI agent would hand its human after shipping a bug: the apology, the deflection, and the quiet implication that the compiler started it. Exactly one line, at most 200 characters.

Entry: `The bug is fixed, and in my defence the compiler started it: the code did exactly what I wrote, which is the problem, and also the reason I am apologising in this font.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
